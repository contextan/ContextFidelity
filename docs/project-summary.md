# ContextPulse 현재 구현 정리

이 문서는 2026-10-09 기준 ContextPulse 프로토타입의 제품 범위와 데모 흐름을 정리한 문서입니다.

## 2026-10-09 제출 준비 상태

- 로컬 앱은 영어 기본 경로와 한국어 `/ko/` 경로에서 동작하며, ChatGPT OAuth 연결과 자동 컨텍스트 선택을 사용할 수 있습니다.
- 실제 모델로 주제 전환 6턴을 확인했습니다. 주제 입력 없이 Product, Design, Submission 대화가 분리되고 이전 주제의 컨텍스트가 섞이지 않았습니다.
- 자동 테스트 78개가 통과했습니다. SQLite 무결성·외래 키·호출 해시 검사도 통과했습니다.
- Docker hosted-mode를 로컬 앱과 같은 ChatGPT OAuth·채팅·모델 선택·컨텍스트 기능으로 맞췄습니다. 방문자별 DB와 암호화 OAuth 자격 증명 분리 테스트를 통과했습니다.
- 브라우저에서 8903의 한국어 채팅·설정, 로그인 진입, 설정 화면에서 중복 OAuth 카드가 제거된 점을 확인했습니다. 실제 모델 선택과 응답은 8903에서 별도 OAuth 로그인을 마친 뒤 확인해야 합니다.
- 8903 loopback 주소에서는 OAuth를 사용할 수 있습니다. 공개 HTTPS 주소는 OpenAI 웹 로그인 클라이언트와 공개 콜백 등록이 선행되어야 하며, Cloudflare 공개 터널과 실제 도메인은 아직 실행하지 않았습니다.
- 로컬 데이터베이스와 인증 정보를 공개 저장소에 포함하지 않습니다. 공개 저장소에는 제품 코드와 문서만 올립니다.

이 검증은 2026-10-09 기준이며, 공개 HTTPS 배포 주소에 대한 검증은 포함하지 않습니다.

## 한 문장 설명

ContextPulse는 대화 주제를 자동으로 파악하고, 현재 질문에 필요한 컨텍스트만 선택해 모델에 전달한 뒤, 답변마다 실제로 사용한 컨텍스트와 원문 근거를 보여주는 로컬 우선 채팅 워크스페이스입니다.

## 사용자가 경험하는 핵심 흐름

1. 왼쪽 아래에서 ChatGPT OAuth에 한 번 로그인하고, 채팅 입력창에서 모델을 선택합니다.
2. 채팅에 질문을 입력합니다. 사용자가 주제를 직접 등록하거나 분류할 필요가 없습니다.
3. 주제 분석은 모델이 수행하고, 프로젝트에 저장된 컨텍스트는 SQLite FTS5 키워드 검색과 점수 임계값으로 최대 8개까지 찾습니다.
4. 선택된 실제 입력으로 답변을 생성하고, 답변 아래에 전달된 컨텍스트 영수증을 표시합니다.
5. 영수증에서 자동으로 파악한 주제, 사용한 저장 컨텍스트, 대화에서 파악한 내용, 이전 대화 수, 원문과 선택 이유를 확인합니다.
6. 사용자 발화의 유용한 맥락은 원문 확인 후 자동 등록합니다. 모델 답변의 제안은 검토 대기 가설로 남고, 승인해야 이후 답변에서 검색됩니다.
7. 필요하면 답변 기록에서 생성·검증·교정·재검증 단계와 각 단계의 실제 요청 본문을 비교합니다.
8. 설정에서 현재 저장소의 프로젝트·대화·컨텍스트·결정·답변·모델 호출 기록을 모두 삭제할 수 있습니다. 로그인과 앱 설정은 유지됩니다.

## 제품 범위

### 포함된 기능

- 프로젝트와 대화 생성·선택
- 질문별 주제 자동 추출
- 배경 정보·참고 자료·검토 중인 가설의 저장, 편집, 버전 이력, 보관·복원·삭제, 검색 및 필터
- SQLite FTS5 BM25 키워드 검색, 키워드·주제 커버리지 점수 임계값, 대화별 포함·제외·자동 선택 복원
- 사용자 발화와 모델 답변에서 컨텍스트 자동 등록
- 모델 답변에서 추출한 가설의 승인·무시 검토 대기열
- 대화에서 파악한 사용자 기준의 별도 목록, 원문 확인, 보관·복원·삭제
- 대화별 삭제. 메시지·답변·호출 기록과 그 대화에서 나온 컨텍스트·기준을 제거하고, 마지막 대화 삭제 시 빈 대화를 생성
- 설정에서 현재 저장소의 모든 대화·컨텍스트·결정·호출 기록 삭제
- 응답 언어와 정확한 항목 수의 불일치를 감지하고, 필요한 경우 한 차례 형식 교정
- 답변별 실제 전달 컨텍스트 영수증과 원문 보기
- 생성 → 원문 근거 검증 → 필요 시 1회 교정 → 재검증
- 단계별 입력·결과·RAW·사용량·지연·해시 보존
- 답변 사이의 호출 입력 비교와 원문 근거 조회
- 한국어(`/ko/`)와 영어 기본 라우트의 분리된 UI 문구
- ChatGPT OAuth와 채팅 입력창 모델 선택. API 키·Ollama를 일반 앱 공급자로 노출하지 않음
- 로컬 실행과 Docker 기반 hosted-mode 테스트

### 결정과 가설 관리

대화에서 파악한 사용자 기준은 컨텍스트 관리 안의 별도 탭에서 원문과 적용 범위를 확인합니다. 활성 기준은 보관하거나 복원할 수 있으며, 대체된 버전은 이력으로 남습니다. 기준을 삭제하면 해당 버전 계열을 제거합니다. 별도의 수동 결정 등록 흐름은 추가하지 않았습니다. 모델 답변의 가설은 자동으로 저장 컨텍스트에 넣지 않고 검토 대기 상태로 보관합니다. 사용자가 승인하면 이후 관련 답변에서 검색하고, 무시하면 다시 제안되지 않습니다.

## 데모에서 보여줄 장면

심사위원에게는 다음 순서가 가장 짧고 명확합니다.

1. 왼쪽 아래에서 ChatGPT OAuth에 로그인한 뒤 채팅 입력창에서 모델 선택
2. 서로 다른 주제의 질문 2~3개 입력
3. 각 답변 아래의 `이번 답변에 전달한 컨텍스트` 열기
4. 질문별 주제와 실제 사용된 컨텍스트, 원문 보기를 확인
5. 다음 질문에서 이전 주제의 컨텍스트가 자동으로 섞이지 않는지 확인
6. `답변 기록`에서 단계별 실제 요청 입력과 비교 화면 열기
7. `컨텍스트 관리`에서 대화 기준과 검토 대기 가설을 확인하고, `설정`에서 데이터 삭제 범위를 확인

## 저장과 보안

- 로컬 데이터는 `data/contextpulse.sqlite`에 저장합니다.
- 인증 정보는 `data/credentials.json`에 별도로 보관하며 저장소와 내보내기에서 제외합니다.
- hosted mode는 방문자별 DB와 암호화된 OAuth 자격 증명을 분리합니다.
- 이전 답변의 전달 입력은 이후 컨텍스트 편집으로 바뀌지 않는 불변 기록입니다.
- 설정의 전체 삭제는 현재 저장소의 대화·컨텍스트·결정·답변 기록을 제거하고 기본 빈 프로젝트를 만듭니다. 개별 대화를 삭제하면 그 대화의 메시지·호출 기록과 해당 대화에서 나온 컨텍스트·결정도 제거하며, 마지막 대화를 지우면 빈 대화를 생성합니다. 개별 컨텍스트·결정을 삭제해도 과거 답변의 실제 전달 기록은 보존됩니다. 로그인과 앱 설정은 유지됩니다. 실제 배포의 백업·보존 정책은 별도 검토가 필요합니다.
- `Context sent`는 실제 보존된 요청 입력의 영수증이며 모델의 주의 집중이나 영향도를 측정하는 기능은 아닙니다.

## 실행

```sh
npm install
npm run build
npm start
```

- 영어: <http://127.0.0.1:8899/>
- 한국어: <http://127.0.0.1:8899/ko/>
- hosted mode 로컬 확인: `docker compose -f compose.yaml up -d --build` 후 <http://127.0.0.1:8903>

## 배포 상태

Cloudflare Tunnel용 compose 설정과 배포 안내는 준비되어 있습니다. 공개 터널과 실제 도메인은 아직 연결하지 않았습니다. 공개 HTTPS에서 ChatGPT OAuth를 쓰려면 OpenAI 웹 로그인 클라이언트와 정확한 콜백 URL 등록이 먼저 필요합니다. 공개 데모를 올리기 전에 이 등록을 완료하고 영구 저장소가 있는 Node origin을 Cloudflare Tunnel에 연결해야 합니다.

## 알려진 제한

- 임베딩 검색과 긴 전체 대화의 무제한 검색은 아직 없습니다.
- 외부 서비스의 기존 대화 가져오기와 데이터 가져오기는 아직 없습니다.
- 데모 모드는 고정된 교정 사례이며 실제 모델의 의미 이해 성능을 벤치마크하지 않습니다.
- OpenAI의 공개 웹 OAuth 클라이언트가 아직 등록되지 않았습니다. 공개 hostname에서 실제 ChatGPT 답변은 사용할 수 없습니다.
- 공개 배포 전에는 실제 HTTPS, Secure cookie, 방문자 격리, 저장소 백업을 별도로 확인해야 합니다.

## 주요 파일

- `src/client.js`: 한국어 UI의 원본과 동작
- `src/client.html`: 공통 셸과 라우트 레이아웃
- `src/pipeline.js`: 생성·검증·교정·재검증 흐름
- `src/context-ai.js`: 주제 선택과 자동 컨텍스트 등록
- `src/store.js`: SQLite 저장과 버전 이력
- `src/auth.js`: ChatGPT OAuth와 계정 상태
- `scripts/build-locales.js`: 영어·한국어 정적 자산 생성
- `docs/cloudflare-demo.md`: hosted mode와 Cloudflare 배포 안내
