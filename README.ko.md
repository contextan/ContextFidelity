# ContextFidelity

ContextFidelity는 대화 주제를 파악해 관련 컨텍스트를 선택하고, 답변마다 모델에 실제 전달한 내용과 원문 근거를 보여주는 오픈소스 로컬 우선 채팅 앱입니다.

[English](README.md)

## 주요 기능

- 질문의 주제를 자동으로 파악하고 현재 프로젝트에서 관련 컨텍스트를 검색합니다.
- 사용자 메시지에서 유용한 정보를 원문과 연결해 자동 등록합니다. 모델이 제안한 내용은 검토 전까지 가설로 보관합니다.
- 사용자가 대화에서 명시한 기준을 배경 정보와 분리해 버전별로 관리합니다. 기준이 바뀌면 이전 기록을 보존하면서 새 기준으로 대체할 수 있습니다.
- 답변을 생성한 뒤 대화 원문 근거와 대조하고, 충돌을 감지하면 한 번 수정한 후 다시 확인할 수 있습니다.
- 답변마다 실제 모델 입력, 포함·제외된 컨텍스트, 검색 점수와 원문 메시지를 영수증으로 보여줍니다. 과거 영수증에는 당시 사용한 내용이 보존됩니다.
- 컨텍스트 항목을 편집·검색·범위 지정·보관·복원·삭제하고, 대화를 삭제할 수 있습니다.

## 컨텍스트 검색 방식

저장된 컨텍스트는 SQLite FTS5로 검색합니다. 기본 점수는 키워드 일치 70%와 주제 일치 30%를 합산합니다. 점수가 50% 이상인 항목을 최대 8개까지 선택하며, 대화별 직접 포함·제외도 지원합니다. 임베딩 기반 의미 검색은 아니므로 겹치는 단어가 없는 바꿔 말하기는 관련 컨텍스트를 찾지 못할 수 있습니다.

## 모델과 데이터

ChatGPT에 한 번 연결한 뒤 채팅 입력창에서 사용할 수 있는 모델을 선택합니다. 주제 분석, 맥락 추출, 검증과 교정에는 연결된 ChatGPT 플랜의 추가 요청이 사용될 수 있습니다. 기존 ChatGPT 대화는 가져오지 않습니다.

기본 구성에서 대화와 컨텍스트는 앱의 SQLite 저장소에 보관합니다. OAuth 인증 정보는 별도 서버 파일에 저장하고 내보내기에서 제외합니다. hosted 모드는 방문자마다 저장소를 분리합니다. 답변 영수증은 모델에 보낸 요청을 기록하지만, 모델이 특정 컨텍스트에 얼마나 주의를 기울이거나 의존했는지를 증명하지는 않습니다.

## 프로토타입의 한계

현재 작동하는 프로토타입이며, 임베딩·의미 검색은 제공하지 않습니다. 충돌 탐지 정확도도 아직 벤치마크하지 않았습니다. 고정 교정 시연은 모델 호출 없이 검토 흐름을 보여주며, 정확도 평가가 아닙니다.
